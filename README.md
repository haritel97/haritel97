### Hi there 👋

I build free, open tools for working with AI, from Malaysia.

**[fillprompt.com](https://fillprompt.com)** · [source](https://github.com/haritel97/fillprompt)<br>
A free library of 6,700+ ready-to-copy AI prompts for images, video and text, each with a sample result and credit to its author. It also runs a free MCP server and a Claude Code plugin, so your AI assistant can search the library and fill a prompt in for you.

```bash
claude mcp add --transport http fillprompt https://fillprompt.com/api/mcp
```

**Working with:** Astro · TypeScript · Tailwind CSS · Vercel · Supabase · MCP
